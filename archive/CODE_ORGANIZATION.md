# CODE_ORGANIZATION.md (New Layout)

## Repos & Roles

- **`vizij-rs`** — Rust workspace **and** the build/publish home for WASM npm packages.
  - Owns all Rust crates (core, Bevy plugins, wasm FFI).
  - Owns the npm **wrapper(s)** that re-export wasm-pack `pkg/`.
  - CI here builds the WASM and **publishes npm packages**.

- **`vizij-web`** — Web monorepo (npm workspaces) that **consumes** published npm packages.
  - React wrappers (if you prefer to keep them here), website, demo apps.
  - CI is Node-only (no Rust), i.e., `npm ci && npm run build`.

This keeps web CI light and lets npm serve as the distribution channel between repos.

## Directory Layouts

### `vizij-rs`

```
vizij-rs/
  Cargo.toml
  crates/
    animation/
      vizij-animation-core/      # engine-agnostic logic
      bevy_vizij_animation/      # Bevy plugin
      vizij-animation-wasm/      # wasm-bindgen FFI (cdylib)
  npm/
    @vizij/animation-wasm/       # npm wrapper that re-exports pkg/
      package.json
      src/index.ts
      pkg/                       # generated by wasm-pack (not committed to git)
```

**wasm-pack out-dir**: `vizij-rs/npm/@vizij/animation-wasm/pkg`

> You can add more controllers later under `crates/...` and mirror npm wrappers under `npm/@vizij/...`.

### `vizij-web`

```
vizij-web/
  package.json                   # npm workspaces + scripts
  packages/
    @vizij/animation-react/      # React provider/hooks that DEPEND on @vizij/animation-wasm (from npm)
  apps/
    demo-animation/              # demo app
    website/                     # (later) main site
```

`vizij-web` **does not contain** the wasm wrapper or `pkg/`; it depends on the one published from `vizij-rs`.

## Naming Conventions

- Core: `vizij-<thing>-core`
- Bevy plugin: `bevy_vizij_<thing>`
- WASM FFI: `vizij-<thing>-wasm`
- npm wrapper: `@vizij/<thing>-wasm`
- React wrapper (if in web): `@vizij/<thing>-react`
