# Support and Exploration Menu

Last updated: 2026-03-09

Use this during the 3:30 pm and 4:30 pm support windows.

## If You Need Help

Pick the lane that best matches your blocker:

1. Install and environment issues
2. Asset loading and GLB confusion
3. Path naming and control-path confusion
4. Animation and merge-model confusion
5. Live-conversation credentials or runtime connection issues

## If You Are Unblocked

Pick one exploration task:

1. Compare two different sample GLBs in `vizij-authoring`.
2. Read `tutorial-fullscreen-face/tutorial.md` and connect it to the live app.
3. Inspect `demo-vizij-player` and identify how it separates assets, controls, and diagnostics.
4. Read the deployment section of `apps/vizij-standalone/README.md`.
5. Write one suggestion for the roadmap breakout later in the day.

## Report-Back Prompts

If you finish an exploration task, be ready to share:

1. One thing you understood better.
2. One friction point you noticed.
3. One change that would make the experience easier for the next participant.
