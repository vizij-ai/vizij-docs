Quick Path Cheat Sheet

Standard Input

rig/{face}/standard/{channel}/{track}/{attribute}

Pose Weight

rig/{face}/poses/{pose_name}.weight

Viseme Weight

rig/{face}/visemes/{viseme_id}.weight

Activity 1: Face Design and Control

What to Do

  1. Open vizij-authoring.
  2. Load a sample GLB.
  3. Find one eye control, one mouth control, and one pose control.
  4. Open tutorial-fullscreen-face.
  5. Move the mouse and press hotkeys to confirm live control.

Success Check

  • I can describe one standard path pattern.
  • I can describe one pose-weight path pattern.
  • I can make a face move on purpose in the runtime.

Notes: What feature path made the most sense to you? What still felt confusing?

Activity 2: Animation, Integration, Deployment

Animation

  • Use demo-vizij-player
  • Identify rigs, clips, and diagnostics
  • Explain how authored clips and live inputs can coexist

Integration

  • Observe tutorial-agent-face
  • Compare baseline, synth, and align mouth modes
  • Notice status chips, expression controls, and lead tuning

Deployment

  • Use vizij-standalone as the deployment anchor
  • Understand the WebSocket control surface
  • Connect the same path model to a robot-facing runtime story

Notes: What changed when the system moved from authored clips to live control?

Support and Exploration

If You Are Blocked

  • Ask for help with install, assets, paths, or runtime behavior.
  • Use the facilitator demo as the reference path.
  • Keep moving through the worksheet even if one live integration fails.

If You Are Unblocked

  • Compare another sample GLB.
  • Inspect runtime hooks in the tutorial app.
  • Write one roadmap or product question for the breakout hour.
