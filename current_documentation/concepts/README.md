# Concepts

This folder is the internal conceptual and reference shelf for Vizij.

Use the guidebook when you want onboarding, learning order, or a reader-facing
route through the system.

Use this folder when you already know the kind of concept you need and want a
compact internal reference surface.

## What This Folder Owns

This folder is best for:

1. shared conceptual definitions that should stay stable across repos,
2. compact internal reference material,
3. targeted technical explainers that do not fit the guidebook's teaching flow,
4. appendices and deeper exploration notes for contributors.

This folder is not the main onboarding route anymore. The guidebook owns broad
learner-facing introduction and narrative progression.

## Relationship To The Guidebook

Use the guidebook first when your question is:

1. what should I learn next,
2. how do these ideas fit into the builder path,
3. which concept should be introduced before another.

Use this folder when your question is:

1. what does this concept mean in compact reference form,
2. where is the internal conceptual explanation for this subsystem,
3. which targeted technical explainer covers this one topic.
