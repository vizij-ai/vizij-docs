# Facilitator Run of Show

Last updated: 2026-03-13

This run-of-show maps the exact workshop schedule to the materials being assembled in this kit.

## 2:30 pm to 2:45 pm: Tutorial Introduction

Objectives:

1. Establish the day’s outcomes.
2. Show a capstone demo so participants know what success looks like.
3. Confirm repo/app setup expectations and fallback norms.
4. Sort the room into ready-to-run and needs-setup clusters without delaying the introduction.

Primary surfaces:

1. `tutorial-agent-face` for the teaser demo
2. Workshop deck introduction slides

Minute plan:

1. `2:30-2:35` outcomes and capstone teaser
2. `2:35-2:40` explain the five demo surfaces and what each one proves
3. `2:40-2:45` state the room rule:
   - participant laptops are welcome
   - facilitator demo is the canonical reference path
   - pair or trio work is the default if setup lags
   - helpers move immediately toward setup blockers while the room keeps going

## 2:45 pm to 3:30 pm: Activity 1, Getting Started with Face Design and Control

Segments:

1. `2:45-2:55` authoring inspection in `vizij-authoring`
2. `2:55-3:10` Hello Face in `tutorial-fullscreen-face`
3. `3:10-3:20` renderer data model and path reasoning
4. `3:20-3:30` recap and checkpoint

Primary surfaces:

1. `vizij-authoring`
2. `tutorial-fullscreen-face`

Facilitator focus:

1. Keep the whole room on one step at a time.
2. Do not let early finishers disappear into deep authoring edits.
3. Push unblocked pairs toward one stretch task only after the main checkpoint is met.

## 3:30 pm to 3:45 pm: Technical Support or Exploration Time

Use this block for:

1. Lane A: setup and app-launch recovery
2. Lane B: path-model and authoring exploration
3. recurring pain-point capture for the breakout hour

## 3:45 pm to 4:30 pm: Activity 2, Face Animation, Integration, and Deployment

Segments:

1. `3:45-4:00` animation and diagnostics in `demo-vizij-player`
2. `4:00-4:15` facilitator-led conversation integration in `tutorial-agent-face`
3. `4:15-4:30` deployment story and control path in `vizij-standalone`

Primary surfaces:

1. `demo-vizij-player`
2. `tutorial-agent-face`
3. `vizij-standalone`

Room rules:

1. Participants may run `demo-vizij-player`.
2. Participants do not need to run `tutorial-agent-face`.
3. Treat deployment as guided architecture plus control-path understanding, not participant binary shipping.

## 4:30 pm to 4:45 pm: Technical Support or Exploration Time

Use this block for:

1. Lane A: setup and app recovery for anyone still blocked
2. Lane B: animation, control, and deployment concept recovery
3. breakout-material prep by at least one helper

## 4:45 pm to 5:00 pm: Coffee Break

Facilitator task during break:

1. Reset demo environments
2. Queue roadmap breakout materials
3. Confirm capture templates are visible on screen or printed
4. Pre-assign groups:
   - roadmap and product priorities
   - research and technical opportunities
   - deployment and adoption risks

## 5:00 pm to 6:00 pm: Vizij Roadmap, Research, and Strategic Planning Breakouts

Outputs expected from each breakout:

1. One prioritized opportunity area
2. One key blocker or open question
3. One proposed next experiment or milestone

Primary source:

1. `vizij-docs/current_documentation/ROADMAP.md`

Timing:

1. `5:00-5:10` group setup and prompt framing
2. `5:10-5:40` group work
3. `5:40` call groups back
4. `5:45-6:00` report-backs and close

## 6:00 pm: Tutorial Concludes

Closing tasks:

1. Recap the learning outcomes.
2. Point participants to next steps and repo surfaces.
3. Capture follow-up questions and breakout outputs.
