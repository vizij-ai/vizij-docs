# Facilitator Run of Show

Last updated: 2026-03-09

This run-of-show maps the exact workshop schedule to the materials being assembled in this kit.

## 2:30 pm to 2:45 pm: Tutorial Introduction

Objectives:

1. Establish the day’s outcomes.
2. Show a capstone demo so participants know what success looks like.
3. Confirm repo/app setup expectations and fallback norms.

Primary surfaces:

1. `tutorial-agent-face` for the teaser demo
2. Workshop deck introduction slides

## 2:45 pm to 3:30 pm: Activity 1, Getting Started with Face Design and Control

Segments:

1. Hello Face: import, export, and control a robot face
2. Renderer data model
3. Rigging: standard and custom control rigs

Primary surfaces:

1. `vizij-authoring`
2. `tutorial-fullscreen-face`

## 3:30 pm to 3:45 pm: Technical Support or Exploration Time

Use this block for:

1. Setup recovery
2. Extra exploration in `vizij-authoring`
3. Stretch tasks in `tutorial-fullscreen-face`

## 3:45 pm to 4:30 pm: Activity 2, Face Animation, Integration, and Deployment

Segments:

1. Real-time conversation integration
2. Animations: define, save, load
3. Deployment: computer to robot

Primary surfaces:

1. `tutorial-agent-face`
2. `demo-vizij-player`
3. `vizij-standalone`

## 4:30 pm to 4:45 pm: Technical Support or Exploration Time

Use this block for:

1. API-key or network recovery for the conversation segment
2. Clip-authoring or deployment troubleshooting
3. Self-directed exploration with facilitator support

## 4:45 pm to 5:00 pm: Coffee Break

Facilitator task during break:

1. Reset demo environments
2. Queue roadmap breakout materials
3. Confirm capture templates are visible on screen or printed

## 5:00 pm to 6:00 pm: Vizij Roadmap, Research, and Strategic Planning Breakouts

Outputs expected from each breakout:

1. One prioritized opportunity area
2. One key blocker or open question
3. One proposed next experiment or milestone

Primary source:

1. `vizij-docs/current_documentation/ROADMAP.md`

## 6:00 pm: Tutorial Concludes

Closing tasks:

1. Recap the learning outcomes.
2. Point participants to next steps and repo surfaces.
3. Capture follow-up questions and breakout outputs.
