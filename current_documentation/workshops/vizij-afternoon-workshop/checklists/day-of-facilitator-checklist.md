# Day-Of Facilitator Checklist

Last updated: 2026-03-13

## Before Participants Arrive

1. Confirm `pnpm install` completed in `vizij-web`.
2. Open the slide deck and `facilitator/demo-command-sheet.md`.
3. Launch and smoke-check:
   - `vizij-authoring`
   - `tutorial-fullscreen-face`
   - `demo-vizij-player`
4. If using the live conversation demo, confirm `VITE_GEMINI_API_KEY` is set locally and the mic permissions are granted.
5. If using the deployment demo, confirm `vizij-standalone` can launch on the presenter machine.
6. Open or print the participant guide, workbook, handouts, and lab sheets.
7. Queue one fallback screen per segment in case a live app stalls.
8. Confirm helpers know their lane assignments.
9. Confirm one shared note surface is ready for recurring issues and breakout capture.

## Right Before 2:30 pm

1. Capstone teaser app open and visible.
2. Intro slide visible.
3. Sample assets easy to reach.
4. Terminals arranged so app restarts are fast.
5. Breakout materials ready for the 5:00 pm block.
6. Pair-or-trio seating plan visible or easy to announce.
7. Helpers know who is handling AV/reset versus room support.

## During Support Windows

1. Run two visible lanes:
   - setup and app recovery
   - path-model and concept exploration
2. Triage by issue cluster instead of one-off debugging.
3. Keep unblocked participants moving with the exploration menu.
4. Log recurring pain points for the breakout or post-workshop notes.

## Before the Breakout Block

1. Open `vizij-docs/current_documentation/ROADMAP.md`.
2. Hand out or display the breakout packet.
3. Assign group reporters and note-takers.
4. Pre-assign groups if the room is large enough to benefit from it.

## Closeout

1. Recap learning outcomes.
2. Point to next docs and repo surfaces.
3. Point participants to the guidebook as the main follow-up reading path.
4. Capture open questions and follow-up requests.
