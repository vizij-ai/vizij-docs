# Release Notes
<!-- tags: family=reference; type=release-notes-index; topics=release-notes,documentation -->
> **Last updated:** 2026-03-31

This directory is the canonical internal home for Vizij release notes and outward-facing change summaries.

## Purpose

Use release notes to explain what changed when Vizij is shared, published, or handed to a broader audience. During the current documentation refresh, this directory is being established as policy and scaffolding first; historical backfill can follow later.

## When to Add a Note

Add or update a release note when one of these happens:

- a package or crate release is published
- a shareable website/tutorial/workshop drop is prepared
- a public-facing example set changes materially
- a breaking API, ABI, file-format, or workflow change lands

## Suggested File Naming

- Versioned release: `vX.Y.Z.md`
- Non-versioned shareable drop: `YYYY-MM-DD-<slug>.md`

## Suggested Structure

1. Summary
2. Highlights
3. Breaking changes or migration notes
4. Docs/tutorial/example updates
5. Related projects or decisions

## Relationship to Other Docs

- `DECISIONS.md` records irreversible choices.
- `ROADMAP.md` records strategic ordering and major priorities.
- release notes explain what actually changed for readers and downstream users.
