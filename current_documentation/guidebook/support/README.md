# Guidebook Support

`Support` is the reusable layer that helps the rest of the guidebook stay practical.

These pages are not a separate learning route. They are the shared validation and recovery tools that other buckets can point to when readers need clearer success criteria or faster recovery.

## Bucket Overview

This section should help readers and facilitators:

1. confirm what success looks like at each route stage,
2. recognize common failure patterns,
3. recover without losing the teaching objective,
4. reuse the same support language across docs, tutorials, and workshops.

## Rule

Support docs should stay reusable across:

1. website pages,
2. tutorials,
3. workshop packets,
4. facilitator fallback paths.
