# Guidebook Reference

These concise modules are the reusable lookup layer behind the maintained route.

Use them when you already know the route you are on and need a compact reminder of:

1. the runtime shell,
2. the path and rigging vocabulary,
3. the animation, integration, and deployment transport contract.

Do not use this bucket as your first stop if you are still deciding where to begin. In that case, go back to [How To Use This Guidebook](../introduction/how-to-use-this-guidebook.md).

## Reference Chooser

| If you mainly need... | Open this reference | Why |
| --- | --- | --- |
| the smallest maintained runtime shell and the key runtime helpers | [Runtime Quickstart](runtime-quickstart-reference.md) | gives the minimum provider/bundle/face shape plus the most common runtime paths |
| a compact reminder of rigging and control-family structure | [Renderer and Rigging Reference](renderer-and-rigging-reference.md) | keeps standard controls, poses, rigging, and naming rules separate |
| the animation/live-integration/deployment transport boundary | [Animation, Integration, and Deployment Reference](animation-integration-and-deployment-reference.md) | keeps clip transport, richer app use, and deployment slot writing in one place |
