# Backlog Structure

The backlog tree is organized by deferred topic area:

1. `authoring/`
2. `runtime/`
3. `code_quality/`

Within each topic area:

1. `summary.md` is the deferred-topic summary
2. named initiative folders hold scoped deferred work
3. `proposals/` holds topic-local intake or exploratory proposals that are not yet active

Use `active_projects/` for live work. Do not recreate the former nested backlog layout.
