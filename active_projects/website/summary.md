# Vizij Website & Ecosystem Program Summary
<!-- tags: status=planning; topics=website,documentation,showcase,cms,automation -->

## Goals
Build a comprehensive, high-quality web presence for Vizij that serves as the central hub for learning, documentation, and community. The site will be hosted in a separate repository, powered by a CMS, and utilize automated workflows to pull documentation directly from source repositories.

## Active Projects

### Architecture & Infrastructure
- **Separate Repository**: Establish a new repo for the website to decouple it from the monorepo.
- **CMS Integration**: Implement a CMS to manage content (blogs, showcase, events) dynamically.
- **Automated Docs**: Build GitHub workflows to sync API docs and guides from `vizij-web` and `vizij-rs` automatically.

### Full Site Sections
- **Home**: Landing page with "wow" factor, explaining Vizij's value proposition.
- **Learn / Tutorials**: Structured learning paths for new users.
- **Reference / Docs**: Comprehensive API and usage documentation (auto-synced).
- **Events**: Calendar or listing of community events/updates.
- **Examples (with Code)**: Interactive examples demonstrating key features.
- **Showcase**: Highlight partners and community projects using Vizij.

### Content Strategy
- **Documentation**: Continuous improvement of guides and API refs.
- **Tutorials**: "Zero to Hero" style content.

## Integration Targets
- **New Animation Editor**: Showcase and document.
- **Arora**: Integration points and case studies.

## Upcoming Milestones
1. **Repo Setup**: Initialize new website repository.
2. **CMS Selection**: Select and integrate CMS.
3. **Docs Sync**: Prototype automated documentation workflow.
