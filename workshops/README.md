# Workshops

This folder is the live home for workshop creation material in `vizij-docs`.

It is for:

1. instructions for creating a new workshop package,
2. reusable scaffold structure,
3. prep guidance that should stay available for the next workshop build.

It is not for:

1. canonical guidebook or current-program documentation,
2. long-lived event packages,
3. delivered workshop snapshots.

## Lifecycle Rule

Use this flow:

1. create or adapt a workshop package from `workshop-template/`,
2. keep active workshop-prep guidance here while the event is being assembled,
3. move the completed event package into `archive/workshops/` after delivery.

## Canonical Technical Ownership

Workshop handouts may intentionally duplicate maintained docs, but the canonical technical source remains outside this folder.

If a workshop handout reveals an evergreen fix:

1. update the maintained guidebook or other canonical doc first,
2. keep workshop-local delivery edits local to the event package,
3. archive the delivered package instead of treating it as an evergreen maintained source.
