# Workshop Template

This scaffold is the starting structure for a new Vizij workshop package.

It is derived from the archived `vizij-afternoon-workshop` event package, but it is intentionally stripped down to instructions and placeholders rather than a standing reusable event.

## How To Use This Template

1. Copy this folder into a working event-specific package location while the workshop is being assembled.
2. Replace placeholder README files with the real event materials you need.
3. Keep canonical technical fixes in maintained docs outside the workshop package.
4. When the event is delivered, move the completed package into `archive/workshops/`.

## Suggested Package Shape

1. `planning/` for source audit, validation plan, and progress tracking
2. `facilitator/` for run-of-show, briefing notes, and demo operations
3. `participant/` for participant guide and workbook surfaces
4. `handouts/` for compact workshop copies of canonical references
5. `checklists/` for prep, day-of, and troubleshooting steps
6. `breakouts/` for feedback and strategy exercises when relevant
7. `slides/` for deck planning, exports, and speaker notes
8. `assets/` for screenshots or workshop-only visuals

## Event Packaging Rule

The template is live. Event packages are not.

Keep this folder focused on reusable creation guidance, then archive any delivered event package separately by date or event name.
